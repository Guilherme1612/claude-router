<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Configured roots → scanner | Filesystem entries, symlinks, and artifact bytes are untrusted inputs constrained to explicit roots. |
| Persisted scan state → diff engine | Cache bytes may be stale, corrupt, incompatible, or path-injected and are never authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Elevation of Privilege / Information Disclosure | fingerprint root traversal | high | mitigate | Canonical realpath containment and portable relative-path validation before reads. |
| T-12-02 | Tampering | persisted fingerprint state | high | mitigate | Version/root-set/schema validation, structured SHA-256 inputs, and clean rescan on any incompatibility. |
| T-12-03 | Information Disclosure | snapshots/events/diagnostics | high | mitigate | Exclude absolute paths and OS-specific inode, device, mode, and mtime data from portable output. |
| T-12-SC | Tampering | package installation | low | accept | No package-manager install occurs; production remains Node standard-library and local ESM only. |
</threat_model>
