<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native metadata to canonical schema | Untrusted local artifact fields enter validated portable records. |
| Identity evidence to merge decision | Claimed shared origins can spoof another runtime capability. |
| Local provenance to portable bytes | Machine paths can disclose private filesystem layout. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Spoofing | stableCapabilityId | high | mitigate | Accept only explicit canonical identity or authoritative shared-origin evidence; test that name/content equality is insufficient. |
| T-11-02 | Tampering | schema validation | high | mitigate | Reject unknown required values and preserve typed conflicts/non-dispatchable states. |
| T-11-03 | Information Disclosure | stableStringify | high | mitigate | Permit logical roots and normalized relative paths only in portable records. |
| T-11-04 | Denial of Service | canonicalization | medium | mitigate | Pure bounded traversal with deterministic rejection of unsupported values and cyclic structures. |
</threat_model>
