<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → CLI canary subcommands | Operator-initiated mutation (promote/rollback) crosses into publication authority; requires exact confirmation to prevent accidental or replay-driven promotion. |
| CLI → canary-controller | router-control.mjs calls applyCanaryDecision which delegates to REGISTRY_PUBLICATION → activate.mjs; the CLI must never write active.json directly. |
| CLI → evidence store | canary status reads the evidence window; a corrupted store could mislead the operator. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-15 | Elevation of Privilege | canary promote without confirmation | high | mitigate | --execute --confirm <candidate_id> gating mirrors the existing rollback verb (router-control.mjs:263-266); confirmation must exactly match candidate_id else reason_code='confirmation_mismatch', exitCode EXIT.usage (Test 4). V4 access-control pattern per RESEARCH.md Security Domain line 641. |
| T-20-16 | Tampering | canary rollback to arbitrary version | high | mitigate | canary rollback destination is recoverActiveVersion known_good_version ONLY (not an arbitrary positional like the existing rollback verb at line 248 — Test 6); reason='canary_rollback' distinct from 'operator_rollback'. Prevents operator using the canary verb to roll back to a non-known-good version. |
| T-20-17 | Tampering | CLI bypasses REGISTRY_PUBLICATION | high | mitigate | canary promote/rollback delegate through applyCanaryDecision → REGISTRY_PUBLICATION → activate.mjs (canary-controller.mjs:135-141); router-control.mjs never calls writeFileSync(active.json) directly. Phase 17 D-decision (STATE.md:140) preserved. |
| T-20-18 | Information Disclosure | canary status leaks sensitive data | low | accept | canary status prints active_version, known_good_version, evidence_window summary (sufficient, sample_count, weighted_samples, source_evidence_fingerprint). No raw prompt text, no prompt signatures (evidence store already strips these per Plan 01). Fingerprints are SHA-256 hashes, not content. |

| T-20-20 | Denial of Service | canary subcommands run on hot path | low | accept | router-control.mjs is an operator CLI invoked manually, NOT the prompt-routing hot path. src/context/prompt-route.mjs is unchanged (grep assertion in done criteria). No <100ms constraint applies to CLI commands. |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | N/A — zero-dependency phase. |
