| Matrix to command runner | Declarative evidence entries select executable local commands and must be constrained to repository-owned tests. |
| Child results to release report | Untrusted output may contain stale, forged, path-sensitive, or private data. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-18-07 | Information disclosure | release report | high | mitigate | Allowlisted structured fields, canonical normalization, privacy sentinels, and no raw child stdout in authority payload. |
| T-18-08 | Denial | release stages | medium | mitigate | Bounded child timeouts, sequential latency isolation, and atomic preservation of prior valid report. |
</threat_model>
