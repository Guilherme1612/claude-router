## Trust Boundaries

| Boundary | Description |
|---|---|
| Operator/automation arguments and stdin to CLI | Untrusted command, format, version ID, reason, and confirmation values enter control logic. |
| CLI to activation module | Only typed-confirmed, fresh, verified rollback may cross the mutation boundary. |
| Repository source to installed runtime roots | Installer copies owned modules near unrelated user configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-13 | Elevation of Privilege | rollback confirmation | high | mitigate | Exact destination ID required; reject generic confirmation, stale preview sequence/fingerprint, invalid version, and direct CLI pointer writes. |
| T-14-14 | Tampering | CLI version/path arguments | high | mitigate | Parse bounded version IDs, resolve through contained activation APIs, reverify immutable destination immediately before mutation, and use stable reason/exit taxonomy. |
| T-14-14A | Tampering | rollback verification-to-publication race | high | mitigate | Inject destination replacement/symlink swap, then require no-follow containment/file-identity/full-manifest revalidation immediately before the shared pointer rename. |
| T-14-15 | Tampering | runtime installation | high | mitigate | Fingerprint-proven ownership, transaction snapshot/restore, complete manifest, readiness/import tests, and refusal to overwrite unowned paths. |
| T-14-16 | Repudiation | text versus JSON output | medium | mitigate | Render both from one canonical result with command, reason code, warnings, preview fingerprint, and audit outcome. |
| T-14-17 | Information Disclosure | status/explain/diff/audit output | medium | mitigate | Portable projection, bounded reason text, and tests rejecting raw prompts, secrets, absolute paths, and control characters. |
| T-14-18 | Denial of Service | unbounded CLI input/diff | medium | mitigate | Enforce argument/value length bounds, deterministic sorted diff limits, and explicit nonzero invalid-state exits. |
</threat_model>
