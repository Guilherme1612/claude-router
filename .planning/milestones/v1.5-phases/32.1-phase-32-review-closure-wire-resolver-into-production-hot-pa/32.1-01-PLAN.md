<objective>
Address review closure item 2 (HIGH): runtime parity is currently bypassable on the index path. `buildTargetIndexes(manifest)` builds one flat `commands` set from `manifest.commands`, ignoring the per-runtime `runtime_commands[RUNTIME]` slice. Because `validateRouteTargets(manifest, modeMap, indexes=buildTargetIndexes(manifest))` and `routeTargetsExist(route, manifest, modeMap, indexes)` both hand `resolveSlashRoute(entry, indexes)` an index, validation can silently evaluate slash-mode/resolve-members against the WRONG runtime inventory. This plan closes that gap by making runtime identity part of `buildTargetIndexes()`.

Purpose: Ensure the active runtime's capability inventory is the ONLY inventory the index paths see, so a Codex-only capability never looks "present" under Claude and vice-versa — the PARITY-03 guarantee holds even when a pre-built index is passed (no valid alternative to the raw manifest now that the index itself is runtime-aware).

Output: runtime-aware `buildTargetIndexes`, byte-identical live-hook mirror, and a focused `tests/router.runtime-index-path.test.mjs` proving index-path runtime isolation.
</objective>
