| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-04 | Elevation of Privilege | adapter traversal | high | mitigate | Realpath canonicalization, separator-aware containment, cycle tracking, revalidation, and exclusion diagnostics run before reads. |

| T-21-07 | Denial of Service | recursive discovery | medium | mitigate | Preserve bounded byte/nesting limits, explicit capability roots, exclusions, sorted traversal, and cycle detection. |
| T-21-SC | Tampering | package installation | high | mitigate | No package installation task exists. |
</threat_model>
