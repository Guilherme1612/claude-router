<interfaces>
The audit input is `{ manifest, modeMap, baseline }` and its output is JSON-ready.
Capability identity is the pair `{ category, id }`; serialize `category:id` only for lookup or display.
Typed reverse references are `mode -> command`, `recommended_skills -> skill`, and `recommended_agents -> agent`; a route entry id is not coverage.
Mapped record schema is `{ category, id, coverage_status: "mapped", classification: null }`.
Unmapped record schema is `{ category, id, coverage_status: "unmapped", classification, reason }`, where classification is exactly one of `gap`, `expected_hook`, `expected_warn_mcp`, `expected_bm25_only`, `expected_phase_internal`, or `expected_scope_project`.
Baseline schema is `{ schema_version: 1, entries: [{ category, id, classification, reason }] }`; only `expected_bm25_only` and `expected_phase_internal` are allowed baseline classifications.
The canonical baseline is `coverage-baseline.json` beside `build-manifest.mjs`: repository root in source and the owned router root after lifecycle installation.
</interfaces>
