## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local overlay → authoritative record | User-controlled structured input requests safety-relevant corrections |
| mutation/lineage → correction lifecycle | Filesystem identity changes may stale or misbind prior approval |

</threat_model>
