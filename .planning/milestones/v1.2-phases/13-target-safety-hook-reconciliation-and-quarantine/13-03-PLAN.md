**Enforcement:** OWASP ASVS Level 1. Blocking threshold: `high`; every high or critical threat must be mitigated before this plan can complete.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native hook config/file -> adapter | Files and bindings are untrusted filesystem/config input with runtime-specific grammar. |
| Adapter observations -> hook join | Normalized references may still be duplicated, mismatched, ambiguous, or scope-inapplicable. |
| Valid pair -> activation authority | Inventory consistency must never be mistaken for permission to register, enable, or activate. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-10 | Spoofing | hook pair identity | high | mitigate | Pair only exact structured runtime/scope/event/reference identities with trusted contained file evidence. |
| T-13-11 | Tampering | binding path/reference | high | mitigate | Reject path escape, mismatch, duplicates, and malformed native structures before joining. |
| T-13-12 | Elevation of Privilege | valid pair handling | high | mitigate | Treat pair as inactive inventory evidence only; no synthesis, registration, install, enable, or activation. |
| T-13-13 | Denial of Service | duplicate/ambiguous hook sets | medium | mitigate | Deterministically classify and quarantine bounded normalized sets instead of selecting a winner. |
| T-13-14 | Information Disclosure | adapter diagnostics | medium | mitigate | Persist only portable logical-root/relative-path evidence and assert absence of host paths. |
</threat_model>

- Do not add external dependencies or machine-specific paths to canonical outputs.
</prohibitions>
