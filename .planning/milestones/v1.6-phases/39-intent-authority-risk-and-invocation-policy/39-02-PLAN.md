| Boundary | Description |
|----------|-------------|
| route suggestion → additionalContext | A pause/ask policy decision is surfaced as a sentinel-wrapped suggestion; the hook never blocks (fail-open) — this is the trust boundary between policy and prompt delivery |
| action-mapper → dispatch invoke | gateAction is the enforceable trust boundary: a proceed reaches invoke(), a pause binds an approval token and diverts to the paused receipt state, an ask returns clarify |
| paused receipt → approval token resume | A paused action resumes only via verifyApproval with a presented+fresh token; a stale/mismatched token fails closed (existing approval.mjs:133-145 behavior) |
| protected-effect vocabulary source | PROTECTED_EFFECT_TOKENS in authority.mjs is the single source of truth; approval.mjs imports it — a capability's side_effects omitting a protected token is backstopped by eligibility gates and contract validation |
