<objective>
Close the three hot-path safety gaps in router.mjs: (SAF-01) fold weights.json mtime into the cache key and expose routing_version for telemetry, (SAF-02) guard cache hits against stale targets by recomputing when the cached route's id/skills/agents are absent from the current manifest, (SAF-04) cap route rendering at 1 mode + 3 skills + 2 agents with drop-and-log before formatInjection.

Purpose: These guards must exist before any mode-map or weights mutation ships in Phases 28-29, so cached routes cannot poison routing or bloat output after a mutation.
Output: Modified router.mjs with four new exports (readWeightsMtime, routeTargetsExist, capRouteRender, extended cacheKey), new tests/router.mutation-safety.test.mjs, extended tests/router.cache.test.mjs.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk (cache.json) → hook process | Cached routes are read from untrusted on-disk cache; a stale or poisoned cache entry crosses this boundary into the hot path |
| disk (manifest) → hook process | Manifest is the trusted source of current capability ids; the stale-target guard validates cache entries against it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-01 | Tampering | cache.json → cache-hit path | high | mitigate | SAF-02 routeTargetsExist guard recomputes instead of serving when cached route targets are absent from manifest (SAF-02) |
| T-27-02 | Tampering | weights.json mtime → cacheKey | high | mitigate | SAF-01 folds weightsMtime into sha256 key so weights edits invalidate stale cache entries (SAF-01) |
| T-27-03 | Denial of Service | formatInjection output size | medium | mitigate | SAF-04 capRouteRender hard count cap (1/3/2/1) before formatInjection prevents oversized injection (SAF-04) |
| T-27-04 | Information Disclosure | telemetry routing_version field | low | accept | routing_version is mtime-derived, contains no prompt text or secret material; existing redaction (router.mjs:1599-1610) unchanged |
