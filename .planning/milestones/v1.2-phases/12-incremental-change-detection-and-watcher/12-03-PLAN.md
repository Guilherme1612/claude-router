<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem notifications → controller | Events may be duplicated, omitted, reordered, filename-less, or flooded. |
| Controller candidate → persisted baseline | Reconcile may fail or observe another change while work is in flight. |
| Repository modules → runtime-owned tree | Installation crosses into Claude/Codex roots and must preserve unrelated state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-07 | Denial of Service | debounce/event flood | high | mitigate | Dirty-root set, bounded maximum latency, single-flight reconcile, and exactly one rerun flag. |
| T-12-08 | Tampering | reconcile state persistence | high | mitigate | Compute before write, atomic persistence only after success, retain last valid baseline on error. |
| T-12-09 | Tampering / Elevation of Privilege | installer-owned runtime files and controller process | high | mitigate | Complete preflight, fingerprinted config/status instance evidence, bounded readiness, cooperative restart/shutdown, transaction rollback, and ownership-safe cleanup. |
| T-12-10 | Information Disclosure | controller state | high | mitigate | Persist only logical roots and normalized relative paths; test absence of temporary absolute roots. |
| T-12-SC | Tampering | package installation | low | accept | No package-manager operation or third-party daemon framework is introduced. |
</threat_model>
