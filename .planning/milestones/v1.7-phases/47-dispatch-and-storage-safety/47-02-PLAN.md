<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Caller-controlled ID -> filesystem | Path traversal or root escape | Validate canonical grammar first, then canonical-root containment. |
| Concurrent caller -> authority record | Last writer replaces a valid lease/checkpoint | Lock read, collision decision, and durable write as one transaction. |
| Filesystem -> runtime authority | Tampering or disclosure | Fail-closed parsing plus 0700/0600 modes and atomic durable writes. |
</threat_model>
