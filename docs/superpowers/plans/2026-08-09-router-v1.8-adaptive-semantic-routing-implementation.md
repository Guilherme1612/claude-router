# Router v1.8 Adaptive Semantic Routing and Continuity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build portable runtime-local semantic routing, least-sufficient capability composition, truthful startup continuity, independent evaluation, and installed Claude/Codex release proof without adding prompt-path weight.

**Architecture:** Extend the existing canonical registry and one production router path. Discovery, contract inference, workflow compilation, preferences, continuity reduction, evaluation, and learning stay off-path; prompt/startup consumers load one bounded atomically published runtime projection. Add only `src/registry/preferences.mjs`, `src/steward/continuity.mjs`, and a repository evaluation entry point.

**Tech Stack:** Node.js ESM, Node standard library, canonical JSON/JSONL, `node:test`, existing registry/prompt/lifecycle modules; no new package or service.
