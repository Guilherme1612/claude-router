<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authorized workflow/semantic closure → strategy planner | Structured upstream facts are inputs and must not create authority or expand scope. |
| strategy output → production dispatch | Strategy data is untrusted planning evidence and must be revalidated by existing dispatch gates before spawn. |
| task/candidate descriptors → cost comparison | Malformed, non-finite, negative, or unbounded values could cause unsafe selection or resource denial. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-43-01 | Elevation of Privilege | `src/orchestrator/strategy.mjs` | high | mitigate | Require matching dispatch-eligible workflow/closure identities and preserve authority, scope, risk, and permission facts as hard constraints; planner output cannot grant permission. |
| T-43-02 | Tampering | candidate/task descriptors | high | mitigate | Reject unknown identities, dependency mismatches, unsafe or incomplete constraint facts, non-finite costs, and resource values outside explicit bounds before selection. |
| T-43-03 | Denial of Service | cost/resource comparison | medium | mitigate | Require finite bounded time, token, call, retry, failure, and coordination fields and expose the selected resource contract for downstream enforcement. |
| T-43-04 | Information Disclosure | strategy report | medium | mitigate | Accept structured facts only and omit raw prompts, secrets, environment, and file contents from the JSON-ready result. |
| T-43-SC | Tampering | package installation | low | accept | No package-manager install is planned; the implementation uses existing ESM modules and Node.js built-ins only. |

High-severity threats block selection when their mitigation fails, consistent with ASVS Level 1 enforcement.
</threat_model>
