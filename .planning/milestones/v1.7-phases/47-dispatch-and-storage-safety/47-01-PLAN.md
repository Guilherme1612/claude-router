<threat_model>
## Trust Boundaries

| Boundary | Risk | Mitigation |
|----------|------|------------|
| Worker -> durable claim | Duplicate execution across processes/restarts | Exclusive create before pending publication or spawn; claim is never removed. |
| Action contract -> child process | Declared limits are advisory only | Validate once, persist immutably, enforce in the shared runner, and record terminal reason codes. |
| Child output -> receipt | Memory growth or data disclosure | Stream counters/hash, cap bytes/lines, and persist hashes plus bounded metadata only. |
</threat_model>
