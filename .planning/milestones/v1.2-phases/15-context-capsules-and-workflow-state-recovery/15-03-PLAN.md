<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Current instruction to resolver | User-controlled target/action data competes with cached intent. |
| Evidence set to dispatch decision | Stale, ambiguous, or conflicting facts could authorize the wrong workflow step. |
| Resolver result to CLI/persistence | Private evidence or unresolved actions could leak or mutate state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-15-09 | Elevation of Privilege | resolver dispatch eligibility | high | mitigate | Exactly-one gate, explicit phrase semantics, terminal-state guard, and no-dispatch clarification outcomes. |
| T-15-10 | Tampering | override and refresh | high | mitigate | Explicit-first precedence, no goal merge, authoritative witnesses, and atomic rewrite only after unique resolution. |
| T-15-11 | Information Disclosure | reason evidence and CLI JSON | high | mitigate | Bounded allowlisted evidence, relative identifiers, stable private errors, and canary assertions. |
| T-15-12 | Repudiation | decision explanation | medium | mitigate | Canonical outcome, source precedence, reason code, and bounded supersession provenance. |
</threat_model>
