Emit a content-address `manifest_fingerprint` epoch over semantic routing inputs and fold it into the hook's `cacheKey`, replacing the 7-position mtime fold. This is the invalidation spine INVC-01/INVC-02 rest on: any semantic inventory change bumps the fingerprint, the cache key changes, and a stale route is recomputed.

</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-30-02 | Spoofing | manifest.manifest_fingerprint | medium | mitigate | Fingerprint is sha256 content-address; the manifest staleness check (mtime vs build script, L413-417) is retained; hook is read-only w.r.t. user code |
