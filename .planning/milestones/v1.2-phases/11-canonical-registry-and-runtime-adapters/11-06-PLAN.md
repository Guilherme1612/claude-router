<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native YAML/TOML bytes to parsed metadata | Untrusted local runtime files enter structured adapter state. |
| Parsed metadata to canonical invocation | Content fields must not become executable invocation without explicit native invocation evidence. |
| Plugin-cache path to portable provenance | Deep versioned local paths may escape roots or disclose machine-specific filesystem details. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-G06-01 | Tampering | YAML/TOML parsers | high | mitigate | Reject duplicate keys, invalid nesting, unterminated strings, and unsupported constructs with stable diagnostics before normalization. |
| T-11-G06-02 | Elevation of Privilege | invocation shaping | high | mitigate | Map only declared native invocation fields; keep multiline instructions as metadata and test that they are never executed or promoted to command arguments. |
| T-11-G06-03 | Denial of Service | nested parser state | high | mitigate | Enforce conservative byte, depth, and collection limits and cover limit failures with deterministic non-dispatchable diagnostics. |
| T-11-G06-04 | Information Disclosure | plugin provenance | high | mitigate | Realpath-check containment before reads and serialize only logical roots, relative paths, and compact package identity. |
| T-11-G06-05 | Spoofing | plugin cache classification | medium | mitigate | Require the complete recognized `.claude/skills/<name>/SKILL.md` suffix beneath an explicit plugin root and preserve source fingerprints/origin evidence. |
</threat_model>
