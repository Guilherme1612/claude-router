<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| active inventory/state files → CLI output | Local authoritative metadata is projected into user-visible and automation-visible output. |
| capability-authored values → terminal/JSON | Untrusted names and authored evidence could leak data or inject presentation controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-16 | Information Disclosure | inventory projection | high | mitigate | Strict field allowlist, logical/relative paths, bounded fingerprints, raw-body/secret/absolute-prefix suppression, and seeded canary tests. |
| T-21-17 | Spoofing | terminal output | high | mitigate | Escape control characters; explicit uppercase labels and state/reason fields carry meaning without ANSI or authored formatting. |
| T-21-18 | Tampering | gap projection | medium | mitigate | Derive only from normalized semantic categories; deterministic sort and runtime-label permutation tests prevent default-framework bias. |
| T-21-19 | Elevation of Privilege | read-only inventory command | high | mitigate | Command reads last-complete state only and exposes no refresh, mutation, installation, dispatch, or policy-authoring path. |
| T-21-SC | Tampering | package installation | high | mitigate | No package installation task exists. |
</threat_model>
