## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem events → reconciliation scheduler | Events are lossy, reordered, and potentially adversarial hints. |
| partial candidate → active authority | Incomplete or failed scans must not become authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-12 | Tampering | event-driven incremental state | high | mitigate | Events select dirty roots only; rescans plus exact full/incremental semantic comparison establish truth. |
| T-21-13 | Denial of Service | incomplete authoritative scan | high | mitigate | Retain last-complete baselines, expose degraded roots/reason, and schedule bounded authoritative retry. |
| T-21-14 | Tampering | concurrent baseline advancement | high | mitigate | Single-flight reconciliation, rerun flag, immutable candidate bytes, and post-publication baseline advancement. |
| T-21-15 | Repudiation | operational inventory state | medium | mitigate | Stable trigger/reason/generation/root metadata records why authority was or was not promoted. |
| T-21-SC | Tampering | package installation | high | mitigate | No package installation task exists. |
</threat_model>
