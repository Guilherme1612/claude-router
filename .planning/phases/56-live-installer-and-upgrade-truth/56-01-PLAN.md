Emit a schema-versioned JSON object containing the resolved roots, capture timestamp, source SHA-256 fingerprints, and per-runtime metadata for the settings/hooks file, install manifest, controller config/status/request/scan-state, active tuple, candidate/report, ownership-listed files, and lifecycle/generation pointers.
