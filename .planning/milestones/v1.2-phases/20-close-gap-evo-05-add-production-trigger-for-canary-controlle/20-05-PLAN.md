<objective>
Close CR-02a and CR-02b — two BLOCKER defects in src/cli/router-control.mjs's `canary` command surface that defeat the operator-driven EVO-05 trigger:

CR-02a (promote surprise-rolls-back on insufficient evidence): the `canary promote --execute --confirm <candidate_id>` branch (lines 437-447) calls applyDecision with `published_version: canaryActive?.version_id ?? null` but has NO evidence-sufficiency gate (unlike the watcher, which gates on window.sufficient). When evidence is insufficient, evaluateCandidate returns `promotable:false` (canary-controller.mjs:112), applyCanaryDecision's rollback branch fires (canary-controller.mjs:176-193) because `!evaluation.promotable` is true and published_version is non-null, and an operator asking to PROMOTE gets a surprise ROLLBACK to known_good_version. This inverts the safety contract (insufficient evidence should PRESERVE, not roll back).

CR-02b (rollback records wrong audit reason): the `canary rollback` branch (lines 480-487) calls applyDecision WITHOUT passing `rollback_reason: 'canary_rollback'`. applyCanaryDecision (canary-controller.mjs:155 accepts `rollback_reason = null`; line 188 uses `reason: rollback_reason || 'rollback'`) — since rollback_reason is undefined, the audit trail records `reason: 'rollback'`, NOT the documented `'canary_rollback'`. The canary rollback verb is indistinguishable from the registry rollback verb in the audit trail, defeating traceability (20-03 truth 4).

Purpose: Restore the safety contract (insufficient evidence preserves, not rolls back) and restore audit-trail traceability (canary rollback distinguishable from registry rollback). These close the operator-driven side of EVO-05's production trigger.

Output: Surgical source fixes — a sufficiency gate inserted in the promote branch before applyDecision is called, and a `rollback_reason: 'canary_rollback'` param added to the rollback branch's applyDecision call — plus two new regression tests. No adjacent CLI code is refactored; the hot path src/context/prompt-route.mjs is untouched.
</objective>
