## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Adapter/build output -> reconciliation | Candidate records, aliases, and lifecycle evidence may be malformed, stale, ambiguous, or adversarial. |

| Local paths -> portable report | Machine-specific paths must not leak into persisted corrective diagnostics. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-13-01 | Spoofing | alias continuity | high | mitigate | Require stable identity plus compatible source evidence; reject similarity-only transfer per D-02. |
| T-13-02 | Tampering | reverse alias index | high | mitigate | Validate and commit each complete alias set immutably; quarantine partial or failed evaluation per D-04. |
| T-13-03 | Information Disclosure | portable verdict evidence | medium | mitigate | Serialize only normalized runtime/scope/logical-root relative evidence and test absence of absolute paths. |
| T-13-04 | Elevation of Privilege | fallback resolution | high | mitigate | Forbid same-name, cross-runtime, cross-scope, and precedence fallback after canonical resolution fails. |
</threat_model>
